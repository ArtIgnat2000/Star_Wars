# Как собрать игру в Scratch 3.0

Есть два пути:

1. **Быстро** — открыть готовый `star_wars_duel.sb3` (Файл → Загрузить с компьютера).
2. **Своими руками** — импортировать фоны и спрайты и собрать скрипты по этой инструкции.
   Это отличное задание для урока: дети повторяют уже работающую логику.

Ниже — точный состав проекта, настройки спрайтов и все скрипты в виде «блок-схем».
Запись `▸` — следующий блок в стопке, отступ — вложенность (внутри «если», «повторять» и т. п.).

---

## 1. Файлы набора

```
assets/
  backdrops/    01-title.svg  02-space.svg  03-naboo.svg  04-generator.svg  05-victory.svg
  sprites/
    quigon/         10 костюмов: стойка, шаг-1…шаг-4, прыжок, удар-1, удар-2, блок, ранен
    obiwan/         10 костюмов (те же имена)
    maul/           10 костюмов (те же имена)
    naboo-fighter/  двигатель-1, двигатель-2, двигатель-3
    droid-fighter/  крылья-открыты, крылья-сложены
    laser/          синий
    enemy-laser/    красный
    explosion/      кадр-1…кадр-4
    sparks/         кадр-1, кадр-2
    plasma-gate/    закрыто, открыто
    dot/            точка  (невидимый «режиссёр» для реплик)
  sounds/         лазер, лазер-врага, меч-вкл, меч-выкл, удар-меча, взрыв,
                  гудение-меча, победа, поражение (.wav)
```

**Импорт фона:** сцена → «Выбрать фон» → «Загрузить» → выбрать `.svg`.
Переименуйте фон так, как в таблице ниже (это важно: скрипты переключают фоны по имени).

**Импорт костюма:** спрайт → вкладка «Костюмы» → «Загрузить» → выбрать `.svg`.
Имена костюмов тоже должны совпадать — на них ссылаются блоки «переключить костюм».

## 2. Переменные (все — «для всех спрайтов»)

| Переменная | Значение на старте | Зачем |
|---|---|---|
| `очки` | 0 | счёт на уровне 1 |
| `жизни` | 3 | здоровье игрока |
| `этап` | 0 | 0 — титул, 1 — космос, 2 — дуэль, 3 — финал |
| `ход` | 0 | 1 — игра идёт, 0 — все циклы останавливаются |
| `хп_мол` | 3 | жизни Дарта Мола |
| `спавн_x`, `спавн_y` | 0 | «почтовый ящик»: куда поставить клона (взрыв, лазер) |
| `блок_игрок` | 0 | игрок держит блок |
| `блок_мол` | 0 | Мол держит блок |
| `атака` | 0 | игрок бьёт |
| `прыжок` | 0 | игрок в прыжке |
| `движется` | 0 | игрок бежит (для анимации) |

Показывать на экране: `очки`, `жизни`, `хп_мол` (последнюю — только на 2 уровне,
блоками «показать переменную» / «скрыть переменную»).

## 3. Сообщения (broadcast)

`меню` · `старт` · `полетели` · `уровень 2` · `бой` · `урон` · `победа` · `поражение`

## 4. Настройки спрайтов

| Спрайт | Костюм(ы) | Размер | Положение | Стиль вращения |
|---|---|---|---|---|
| Истребитель | двигатель-1…3 | 55 % | x 0, y −110 | не вращать |
| Лазер | синий | 100 % | скрыт | — |
| Лазер врага | красный | 100 % | скрыт | — |
| Дроид-истребитель | крылья-открыты | 42 % (ставится в скрипте) | скрыт | не вращать |
| Взрыв | кадр-1…4 | 58 % | скрыт | — |
| Плазма-врата | закрыто/открыто | 60 % | x −205, y −60 | — |
| Квай-Гон | 10 костюмов | 70 % | x −195, y −45 | влево-вправо |
| Оби-Ван | 10 костюмов | 70 % | x −90, y −45 | влево-вправо |
| Дарт Мол | 10 костюмов | 70 % | x 120, y −45 | влево-вправо |
| Искры | кадр-1/2 | 70 % | скрыт | — |
| Режиссёр | точка | 100 % | x 0, y −30 | — |

Порядок слоёв снизу вверх: Истребитель → Лазер → Лазер врага → Дроид → Взрыв →
Плазма-врата → Квай-Гон → Оби-Ван → Дарт Мол → Искры → Режиссёр.

У спрайтов персонажей **центр костюма — по центру холста**, поэтому «y = −45» ставит
ноги на линию пола. Если вы импортировали SVG вручную, Scratch поставит центр так же.

## 6. Спрайт «Режиссёр» (невидимый, говорит реплики)

Костюм «точка» — крошечная почти прозрачная точка. В скрипте ставим эффект
«призрачность» 100 %, тогда спрайт не виден, но «облачко» с текстом показывается.

```
когда щёлкнут по ⚑
▸ задать эффект [призрачность] = 100
▸ перейти в x: 0 y: −30
▸ всегда
    ▸ если <клавиша [пробел] нажата?> то
        ▸ если <(этап) = 0> то
            ▸ передать [старт]
            ▸ ждать 1.6 секунды
          иначе
            ▸ если <(этап) = 3> то
                ▸ передать [старт]
                ▸ ждать 1.6 секунды
```

Реплики (каждая — отдельный скрипт «когда я получу …»):

| Сообщение | Текст |
|---|---|
| `меню` | «Звёздные войны: Дуэль на Набу. Нажми ПРОБЕЛ, чтобы начать игру.» (5 с) |
| `полетели` | «Уровень 1 — космос. Стрелки ← → манёвр, ПРОБЕЛ — огонь. Сбей 8 дроидов!» (5 с) |
| `бой` | ждать 0.6 с → «Уровень 2 — Дарт Мол! ← → бег, ↑ прыжок, ПРОБЕЛ удар мечом, ↓ блок.» (6 с) |
| `победа` | ждать 1.8 с → «Победа! Тёмная сторона отступила. Нажми ПРОБЕЛ, чтобы сыграть снова.» (6 с) |
| `поражение` | ждать 2.2 с → «Поражение… Нажми ПРОБЕЛ, чтобы попробовать снова.» (5 с) |

## 7. Уровень 1 — «Погоня над Набу»

### Спрайт «Истребитель»

Звуки спрайта: `лазер`, `взрыв`.

```
когда щёлкнут по ⚑ → спрятаться
когда я получу [старт] → спрятаться
когда я получу [уровень 2] → спрятаться
когда я получу [победа] / [поражение] → спрятаться
```

```
когда я получу [полетели]
▸ показаться
▸ задать размер 55 %
▸ задать стиль вращения [не вращать]
▸ повернуть в направление 90
▸ перейти в x: 0 y: −110
▸ задать эффект [призрачность] = 0
▸ переключить костюм на [двигатель-1]
```

```
когда я получу [полетели]
▸ повторять пока не <(ход) = 0>
    ▸ если <клавиша [стрелка вправо] нажата?> → изменить x на 9
    ▸ если <клавиша [стрелка влево] нажата?> → изменить x на −9
    ▸ если <(x position) > 200> → задать x = 200
    ▸ если <(x position) < −200> → задать x = −200
    ▸ следующий костюм
    ▸ ждать 0.07 секунды
```

```
когда я получу [полетели]
▸ повторять пока не <(ход) = 0>
    ▸ если <клавиша [пробел] нажата?> то
        ▸ создать клон [Лазер]
        ▸ играть звук [лазер]
        ▸ ждать 0.25 секунды
    ▸ ждать 0.02 секунды
```

```
когда я получу [полетели]
▸ ждать до <(очки) > 79>
▸ передать [уровень 2]
```

```
когда я получу [урон]
▸ если <(этап) = 1> то
    ▸ изменить [жизни] на −1
    ▸ играть звук [взрыв]
    ▸ повторить 3
        ▸ задать эффект [призрачность] = 65
        ▸ ждать 0.08 секунды
        ▸ задать эффект [призрачность] = 0
        ▸ ждать 0.08 секунды
    ▸ если <(жизни) < 1> то
        ▸ передать [поражение]
        ▸ спрятаться
```

### Спрайт «Лазер» (синий)

```
когда щёлкнут по ⚑ → спрятаться
```

```
когда я начинаю как клон
▸ переключить костюм на [синий]
▸ перейти в x: ([x position] объекта [Истребитель])
              y: ([y position] объекта [Истребитель] + 46)
▸ показаться
▸ повторить 26
    ▸ изменить y на 15
    ▸ если <касается [Дроид-истребитель]?> → удалить этот клон
    ▸ если <(y position) > 188> → удалить этот клон
▸ удалить этот клон
```

> Блок «[x position] объекта [Истребитель]» — это `sensing of` («сенсор» → «[свойство] объекта [спрайт]»).

### Спрайт «Лазер врага» (красный)

Звук: `лазер-врага`.

```
когда щёлкнут по ⚑ → спрятаться

когда я начинаю как клон
▸ переключить костюм на [красный]
▸ перейти в x: (спавн_x) y: (спавн_y)
▸ показаться
▸ играть звук [лазер-врага]
▸ повторять пока не <<касается [Истребитель]?> или <(y position) < −178>>
    ▸ изменить y на −9
▸ если <касается [Истребитель]?> → передать [урон]
▸ удалить этот клон
```

### Спрайт «Дроид-истребитель»

Звук: `взрыв`.

```
когда щёлкнут по ⚑ → спрятаться
когда я получу [старт] → спрятаться
когда я получу [уровень 2] → спрятаться

когда я получу [полетели]
▸ повторять пока не <(ход) = 0>
    ▸ создать клон [самого себя]
    ▸ ждать (выдать случайное от 0.55 до 1.15) секунды
```

```
когда я начинаю как клон
▸ показаться
▸ задать размер 42 %
▸ переключить костюм на [крылья-открыты]
▸ перейти в x: (случайное от −205 до 205) y: 196
▸ повторять пока не <<(y position) < −196> или <(ход) = 0>>
    ▸ изменить y на −3.6
    ▸ если <касается [Лазер]?> то
        ▸ изменить [очки] на 10
        ▸ играть звук [взрыв]
        ▸ задать [спавн_x] = (x position)
        ▸ задать [спавн_y] = (y position)
        ▸ создать клон [Взрыв]
        ▸ ждать 0.03 секунды
        ▸ удалить этот клон
    ▸ если <касается [Истребитель]?> то
        ▸ передать [урон]
        ▸ задать [спавн_x] = (x position)
        ▸ задать [спавн_y] = (y position)
        ▸ создать клон [Взрыв]
        ▸ удалить этот клон
    ▸ если <(случайное от 1 до 100) > 98> то
        ▸ задать [спавн_x] = (x position)
        ▸ задать [спавн_y] = ((y position) − 18)
        ▸ создать клон [Лазер врага]
    ▸ ждать 0.04 секунды
▸ удалить этот клон
```

> `спавн_x` / `спавн_y` нужны потому, что клон не может спросить «где тот клон».
> Дроид записывает свои координаты в переменные, а клон взрыва читает их.

### Спрайт «Взрыв»

```
когда щёлкнут по ⚑ → спрятаться

когда я начинаю как клон
▸ перейти в x: (спавн_x) y: (спавн_y)
▸ задать размер 58 %
▸ переключить костюм на [кадр-1]
▸ перейти на передний план
▸ показаться
▸ следующий костюм → ждать 0.06
▸ следующий костюм → ждать 0.07
▸ следующий костюм → ждать 0.09
▸ удалить этот клон
```

## 8. Уровень 2 — «Дуэль в генераторной»

### Спрайт «Оби-Ван» (игрок)

Звуки: `меч-вкл`, `удар-меча`.

```
когда щёлкнут по ⚑ → спрятаться
когда я получу [старт] → спрятаться

когда я получу [бой]
▸ показаться
▸ задать размер 70 %
▸ задать стиль вращения [влево-вправо]
▸ повернуть в направление 90
▸ перейти в x: −90 y: −45
▸ задать эффект [призрачность] = 0
▸ переключить костюм на [стойка]
▸ задать [блок_игрок] = 0
▸ задать [атака] = 0
▸ задать [прыжок] = 0
▸ задать [движется] = 0
```

**Движение, поворот и прыжок:**

```
когда я получу [бой]
▸ повторять пока не <(ход) = 0>
    ▸ задать [движется] = 0
    ▸ если <<клавиша [стрелка вправо] нажата?> или <клавиша [d] нажата?>> то
        ▸ изменить x на 6
        ▸ задать [движется] = 1
    ▸ если <<клавиша [стрелка влево] нажата?> или <клавиша [a] нажата?>> то
        ▸ изменить x на −6
        ▸ задать [движется] = 1
    ▸ если <(x position) > 160> → задать x = 160
    ▸ если <(x position) < −160> → задать x = −160
    ▸ если <(x position) > ([x position] объекта [Дарт Мол])> то
          ▸ повернуть в направление −90
      иначе → повернуть в направление 90
    ▸ если <<<клавиша [стрелка вверх] нажата?> или <клавиша [w] нажата?>> и <(прыжок) = 0>> то
        ▸ задать [прыжок] = 1
        ▸ переключить костюм на [прыжок]
        ▸ повторить 12 → изменить y на 11 → ждать 0.02
        ▸ повторить 12 → изменить y на −11 → ждать 0.02
        ▸ задать [прыжок] = 0
        ▸ переключить костюм на [стойка]
    ▸ если <<(движется) = 1> и <<(атака) = 0> и <<(блок_игрок) = 0> и <(прыжок) = 0>>>> то
        ▸ следующий костюм
        ▸ если <(костюм number) > 5> → переключить костюм на [шаг-1]
      иначе
        ▸ если <<(атака) = 0> и <<(блок_игрок) = 0> и <(прыжок) = 0>>> то
            ▸ переключить костюм на [стойка]
```

**Удар мечом:**

```
когда я получу [бой]
▸ повторять пока не <(ход) = 0>
    ▸ если <<клавиша [пробел] нажата?> и <(атака) = 0>> то
        ▸ задать [атака] = 1
        ▸ переключить костюм на [удар-1]
        ▸ ждать 0.1 секунды
        ▸ переключить костюм на [удар-2]
        ▸ играть звук [удар-меча]
        ▸ если <(расстояние до [Дарт Мол]) < 100> то
            ▸ задать [спавн_x] = ([x position] объекта [Дарт Мол])
            ▸ задать [спавн_y] = (([y position] объекта [Дарт Мол]) + 35)
            ▸ создать клон [Искры]
            ▸ если <(блок_мол) = 0> то
                ▸ изменить [хп_мол] на −1
                ▸ если <(хп_мол) < 1> → передать [победа]
        ▸ ждать 0.2 секунды
        ▸ переключить костюм на [стойка]
        ▸ задать [атака] = 0
```

**Блок:**

```
когда я получу [бой]
▸ повторять пока не <(ход) = 0>
    ▸ если <<клавиша [стрелка вниз] нажата?> или <клавиша [s] нажата?>> то
        ▸ задать [блок_игрок] = 1
        ▸ если <(атака) = 0> → переключить костюм на [блок]
      иначе
        ▸ задать [блок_игрок] = 0
```

**Реакции:**

```
когда я получу [урон]
▸ если <(этап) = 2> то
    ▸ переключить костюм на [ранен]
    ▸ ждать 0.32 секунды
    ▸ если <(атака) = 0> → переключить костюм на [стойка]

когда я получу [победа]
▸ повторить 3
    ▸ изменить y на 16 → ждать 0.12 → изменить y на −16 → ждать 0.12
▸ переключить костюм на [стойка]

когда я получу [поражение]
▸ переключить костюм на [ранен]
▸ ждать 1.2 секунды
▸ повторить 8 → изменить эффект [призрачность] на 12 → ждать 0.06
▸ спрятаться
```

### Спрайт «Дарт Мол» (противник)

Звуки: `удар-меча`, `гудение-меча`.

```
когда щёлкнут по ⚑ → спрятаться
когда я получу [старт] → спрятаться

когда я получу [бой]
▸ показаться
▸ задать размер 70 %
▸ задать стиль вращения [влево-вправо]
▸ повернуть в направление −90
▸ перейти в x: 120 y: −45
▸ задать эффект [призрачность] = 0
▸ переключить костюм на [стойка]
▸ задать [блок_мол] = 0
```

**Искусственный интеллект:**

```
когда я получу [бой]
▸ повторять пока не <(ход) = 0>
    ▸ если <(x position) > ([x position] объекта [Оби-Ван])>
          ▸ повернуть в направление −90
      иначе → повернуть в направление 90
    ▸ если <(расстояние до [Оби-Ван]) > 92> то
          ▸ если <(x position) > ([x position] объекта [Оби-Ван])>
                ▸ изменить x на −5
            иначе → изменить x на 5
          ▸ следующий костюм
          ▸ если <(костюм number) > 5> → переключить костюм на [шаг-1]
      иначе
          ▸ если <(случайное от 1 до 10) > 7> то
                ▸ задать [блок_мол] = 1
                ▸ переключить костюм на [блок]
                ▸ ждать 0.5 секунды
                ▸ задать [блок_мол] = 0
                ▸ переключить костюм на [стойка]
            иначе
                ▸ переключить костюм на [удар-1]
```

## 9. Частые ошибки и как их поймать

| Симптом | Причина |
|---|---|
| Игра не начинается по ПРОБЕЛУ | не задан `этап = 0` на флаге, или «Режиссёр» спрятан блоком **спрятаться** вместо эффекта «призрачность» 100 |
| Игрок проходит сквозь Мола | проверяется `расстояние до` без условия «≤», либо Мол не в слое перед игроком |
| После победы всё продолжает летать | забыли `задать [ход] = 0` перед сменой уровня |
| Взрывы появляются в углу | клон не читает `спавн_x`/`спавн_y`, а наследует позицию оригинала |
| Клоны дроидов плодятся после рестарта | нет условия `(ход) = 0` в цикле спавна |
| Костюм «залипает» на ударе | скрипт удара не вернул `атака = 0` / не переключил на «стойка» |
| Звук не играет | имя звука в блоке не совпадает с именем файла в спрайте |

Проверять удобно так: включите в редакторе «Следить за переменными» и смотрите,
как меняются `этап`, `ход`, `жизни`, `хп_мол`.

## 10. Что можно менять без страха

- **Сложность 1 уровня:** условие победы `очки > 79` → поставьте 39 (4 дроида) или 119 (12).
- **Скорость дроидов:** `изменить y на −3.6` → −2.5 (легче) или −5 (сложнее).
- **Частота выстрелов:** `случайное от 1 до 100 > 98` → >95 (чаще) или >99 (реже).
- **Здоровье Мола:** `хп_мол = 3` → 5.
- **Реакция Мола:** порог `расстояние > 92` и пауза `0.06` в его цикле.
- **Реплики:** все тексты — в скриптах спрайта «Режиссёр».
